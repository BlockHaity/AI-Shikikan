## 它是什么

AI-Shikikan是一款可以将多个终端Agent集合在一起，并让AI统一指挥调度这些Agent的终端/图形程序

## 功能

 - 让AI调用主流Agent程序(Claude Code,OpenCode,Reasonix)
 - 可配置的，让不同的Agent使用不同的模型去完成对应的任务
 - 对自身/Agent程序注入角色扮演/专家文件

## 支持的API

 - OpenAI Style
 - Anthropic Style
